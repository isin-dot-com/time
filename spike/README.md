# Пробная сборка (spike): окно дня на экране блокировки

Одноразовое приложение, которое отвечает на шесть вопросов из раздела 10 `docs/product-design.md`
(«Что должна ответить пробная сборка»). Дизайна нет, всё на системных элементах.
Всё, что происходит, пишется в **журнал** внизу экрана: со временем, сохраняется между запусками.
Записи туда попадают и тогда, когда приложение закрыто, но его будит кнопка виджета или «Команды».

## Сборка

GitHub → Actions → **Spike to TestFlight** → *Run workflow*. Около 20 минут. Номер сборки равен номеру запуска.
Сборка уходит в App Store Connect, через 5–30 минут появляется в TestFlight.
Если запуск упал, логи лежат в артефакте `spike-logs-<номер>`.

Картинки, шрифт и звуки уже лежат в репозитории. Пересоздать их можно так: `pip install fonttools pillow && python spike/tools/make_assets.py`.

## Что на экране

| Элемент | Что проверяет |
|---|---|
| Верхние строки: сборка, `areActivitiesEnabled`, образец своего шрифта «загружен / НЕ загружен» | Окна разрешены; шрифт загрузился в самом приложении |
| «Запросить разрешение на уведомления» | Зависит ли звук оповещения от разрешения на уведомления (вопрос 3). Текущее состояние пишется в журнал при каждом запуске |
| **Настройки → Шрифт цифр**: «Свой шрифт» / «Системный» | Вопрос 6. Свой шрифт рисует цифры палочками, как на электронных часах. Если в окне цифры обычные, шрифт не загрузился в расширении |
| **Настройки → staleDate**: нет / +1м / +2м / +5м / ½ | Вопрос 2. Через сколько минут после начала отрезка окно само сменит фразу **A** на фразу **B**. ½ — середина отрезка (максимум 8 часов) |
| **Настройки → Звук**: системный / `quiet.wav` / `silent.wav` / `silent` без расширения | Вопрос 3. Звук оповещения, когда запланированное окно стартует само |
| **1. Окно сейчас**: время конца, «Старт сейчас» | Обычный запуск: тикающий отсчёт, системная полоса, фраза A, затем переход на B после staleDate |
| **2. Запланировать**: «Через 2 мин», «Через 10 мин» | Запуск по расписанию iOS 26 (`start:`) и оповещение при старте |
| «3 подряд по 3 мин» | Три отрезка встык: как система показывает несколько окон одного приложения |
| «Завтра 08:00», «Завтра и послезавтра 08:00» | Вопрос 1: стартуют ли окна на следующий день без открытия приложения |
| «Лимит: до 12 шт.» | Вопрос 1: сколько запланированных окон принимает система. Останавливается на первой ошибке, ошибка пишется в журнал |
| «Дальность: +3/+7/+14/+28 дней» | Вопрос 1: насколько далеко вперёд можно планировать |
| **3. Окна приложения**: список с состоянием (pending / active / stale / ended / dismissed), «Обновить», «Завершить все» | Состояния окон. Пока приложение открыто, список обновляется каждые 2 секунды; изменения состояний пишутся в журнал как `[снимок] … pending → active` |
| Кнопка ↻ в самом окне | Кнопка «другая фраза» (`LiveActivityIntent`). Меняет ту фразу, которая сейчас на экране |
| Виджет экрана блокировки «До отбоя (spike)» (прямоугольный): отсчёт до 23:00 и кнопка ▶ | Вопрос 4: запускается ли окно кнопкой из виджета |
| Действие «Начать день (spike)» в приложении «Команды» | Вопрос 5: автоматизация по времени на заблокированном телефоне |
| Dynamic Island | Свёрнутый вид (слева кольцо, справа таймер), минимальный (только кольцо), развёрнутый (долгое нажатие) |

В окне вверху написано: название отрезка · метка теста · `custom`/`system` (шрифт), справа **A** или **B · stale**.

## Перед началом (один раз)

1. Установить сборку из TestFlight и открыть приложение.
2. Настройки iPhone → Time Spike → **Live Activities: вкл.**
3. Если окна не появляются или Dynamic Island пустой, хотя в журнале `OK`: **перезагрузить телефон**. Известная проблема iOS после установки обновления через TestFlight.
4. Режим «Не беспокоить» и фокусы выключить. Звонок не в беззвучном режиме: кнопка действия / Пункт управления.
5. В конце каждого теста нажимать **«Завершить все»**, чтобы окна одного теста не мешали следующему (лимит окон общий).

## Сценарий проверки

Для каждого шага: скриншот экрана блокировки или острова и **«Копировать всё»** из журнала (вставить в заметку или сообщение).

### Вопрос 6 и проверка отображения (5 минут, начать с него)
1. Шрифт «Свой шрифт», staleDate «нет», конец «+30 мин» → **Старт сейчас**.
2. Шрифт «Системный» → **Старт сейчас** ещё раз.
3. Заблокировать телефон. На экране два окна.
   - Скриншот. Цифры в окне `custom` нарисованы палочками? Цифры тикают каждую секунду? Полоса убывает?
4. Разблокировать, выйти на домашний экран: Dynamic Island. Скриншот свёрнутого вида. Долгое нажатие → скриншот развёрнутого.
5. Минимальный вид: запустить таймер в «Часах», остров поделится. Скриншот.
6. Нажать ↻ в окне на экране блокировки. Фраза A сменилась? Попросил ли телефон Face ID? В журнале должна появиться строка `SwapPhraseIntent`.
7. **Завершить все.**

**Ответ:** свой шрифт в окне работает (да/нет), отсчёт тикает (да/нет), кнопка ↻ работает (да/нет, нужна ли разблокировка).

### Вопрос 2: окно само меняет фразу (5 минут)
1. staleDate **+2м**, конец «+30 мин» → **Старт сейчас**. Заблокировать телефон, экран не гасить (или поднять телефон на 2-й минуте).
2. Через 2 минуты фраза в окне должна смениться с «A: …» на «B: …», а справа вверху появиться «B · stale». Без касаний.
3. Скриншот до и после. Записать, через сколько секунд после отметки 2:00 произошла смена. Сменилось ли на погасшем экране или только после пробуждения?
4. Повторить с запланированным окном: staleDate +2м → **Через 2 мин**. Смена ожидается примерно через 4 минуты после нажатия.
5. **Завершить все.**

**Ответ:** окно переключается само (да/нет), с какой задержкой, и работает ли это у запланированного окна.

### Вопрос 3: тихое оповещение (по 3 минуты на вариант)
Для каждого варианта звука: системный, `quiet.wav`, `silent.wav`, `silent` без расширения:
1. Выбрать звук → **Через 2 мин**. Заблокировать телефон, положить экраном вверх.
2. В момент старта записать: был ли звук, какой (стандартный или тихий писк), вибрация, загорелся ли экран, баннер или развёрнутый остров.
3. **Завершить все.**

Потом нажать «Запросить разрешение на уведомления», ответить **«Не разрешать»** и повторить `silent.wav`. Затем в Настройках разрешить уведомления и повторить ещё раз.

**Ответ:** таблица «вариант × звук / вибрация / экран». Есть ли по-настоящему беззвучный вариант.

### Вопрос 1: планирование вперёд и лимит (тест на ночь)
1. **Завершить все.** Нажать **«Лимит: до 12 шт.»**. В журнале строка `← тест лимита: принято N` и текст ошибки на N+1-м окне (например, `targetMaximumExceeded`). Скриншот журнала и списка окон (сколько `pending`).
2. **Завершить все.** Нажать **«Дальность»**. Какие из +3/+7/+14/+28 дней приняты, какие с ошибкой. Скриншот журнала.
3. **Завершить все.** staleDate **½**, звук на выбор → **«Завтра и послезавтра 08:00»**. В списке должны быть 2 окна `pending`. Скриншот.
4. **Приложение больше не открывать** до послезавтра. Не смахивать его из переключателя и не открывать.
5. Завтра в 08:00: появилось ли окно и оповещение? Скриншот экрана блокировки. Около 12:00 переключилось ли на фразу B? Около 16:00 окно должно закончиться по лимиту 8 часов: что стало с окном (исчезло, застыло)?
6. Послезавтра в 08:00: то же самое.
7. После этого открыть приложение: журнал покажет `[снимок, открытие экрана] … pending → …`. Скопировать журнал.

**Ответ:** стартуют ли окна на завтра и послезавтра без открытия приложения; сколько окон система принимает одновременно; насколько далеко вперёд можно планировать.

### Вопрос 4: кнопка в виджете на заблокированном экране (5 минут)
1. Долгое нажатие на экран блокировки → Настроить → Экран блокировки → добавить виджет **Time Spike → «До отбоя (spike)»** (прямоугольный). Отсчёт до 23:00 должен тикать.
2. **Завершить все.** Заблокировать телефон, подождать, пока экран погаснет, затем поднять телефон.
3. Нажать ▶ в виджете. Записать: попросил ли Face ID или код, появилось ли окно, через сколько секунд.
4. Повторить с разблокированным телефоном (Face ID прошёл, экран блокировки ещё открыт).
5. Открыть приложение: в журнале должны быть `процесс приложения запущен` и `StartDayIntent.perform: источник=виджет, состояние приложения=background`. Скопировать журнал.

По документации Apple кнопки в виджетах на заблокированном устройстве не срабатывают без разблокировки. Проверяем, как это выглядит на самом деле.

**Ответ:** запускается ли окно кнопкой из виджета; нужна ли разблокировка.

### Вопрос 5: автоматизация «Команд» на заблокированном телефоне (10 минут)
1. «Команды» → Автоматизация → «+» → **Время суток** → время через 3 минуты, «Ежедневно» → **«Запускать сразу»** (не «После подтверждения»), уведомление о запуске выключить.
2. Действие: найти приложение **Time Spike** → **«Начать день (spike)»**. Сохранить.
3. **Завершить все.** Заблокировать телефон, экран погаснет. Ждать.
4. В назначенное время: появилось ли окно на экране блокировки? Было ли уведомление от «Команд»?
5. Открыть приложение: в журнале `StartDayIntent.perform: источник=команда/Siri`. Скопировать журнал.
6. Удалить автоматизацию после теста.

**Ответ:** запускает ли автоматизация окно на заблокированном телефоне.

## Что прислать

- Номер сборки (вверху экрана приложения) и версию iOS.
- Скриншоты по каждому вопросу.
- Полный журнал («Копировать всё»), вставленный текстом.
- Короткие ответы на 6 вопросов в формате «да/нет + детали».
